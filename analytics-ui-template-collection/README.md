# 📊 Analytics UI Template Collection

A collaborative Web UI Template Collection built by a 5-member team using HTML, CSS, JavaScript and GitHub.

## Team Distribution

| Member | Main Category | Templates |
|---|---|---|
| Member 1 | Analytics Overview | Overview Dashboard, KPI Dashboard, Customizable Dashboard |
| Member 2 | Revenue & Sales | Revenue Dashboard, Sales Analytics, Financial Reports |
| Member 3 — You | User & Customer Analytics | User Analytics, Customer Analytics, Retention & Cohort |
| Member 4 | Marketing Analytics | Marketing Dashboard, Conversion Funnel, Campaign Analytics |
| Member 5 | Real-Time Analytics | Real-Time Dashboard, Live Activity Monitor, Analytics Monitoring |

**Total: 15 UI templates**

## Technologies

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Run Locally

Open `index.html` in a modern web browser.

For best results with local development, use VS Code with the Live Server extension.

## GitHub Workflow

Fork → Clone → Branch → Develop → Commit → Push → Pull Request → Review → Merge

## Project Goal

The goal is to practice real-world GitHub collaboration while creating original, responsive and modern analytics UI patterns.

## Main Page

The root `index.html` is the collection homepage. It contains links to all 15 team templates according to the repository structure.
