# Contributing

Thank you for contributing to the Analytics UI Template Collection.

## Workflow

1. Fork the repository.
2. Clone your fork.
3. Create a separate feature branch.
4. Develop your assigned UI.
5. Test the UI in a modern browser.
6. Commit with a meaningful message.
7. Push your branch.
8. Create a Pull Request.
9. Review another team member's Pull Request.
10. Make requested changes if necessary.
11. Merge after approval.

## Coding Guidelines

- Use meaningful HTML elements and class names.
- Keep CSS organized and readable.
- Use JavaScript only where interaction is required.
- Keep each template inside its assigned folder.
- Make every UI responsive.
- Do not copy an existing website.
